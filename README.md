
# Excel Sales Dashboard – Executive Summary & Profitability Analysis

## Project Overview
An interactive Excel dashboard developed to analyze sales performance, revenue, profitability, and regional trends using PivotTables, PivotCharts, and interactive slicers.

## Dashboard Preview

![Excel Sales Dashboard](dashboard.png)

## Key Features
- KPI tracking: Total Revenue, Gross Profit, Profit Margin, Units Sold, Total Orders, and COGS.
- Monthly Revenue and Profit Analysis.
- Top 5 Countries by Revenue.
- Revenue Share by Sales Channel.
- Region-wise Performance Comparison.
- Country-wise Revenue Map.
- Interactive slicers for Product Category, Country, and Quarter.

## Tools & Technologies
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Visualization
- KPI Analysis

## Key Insights
Analyzed monthly sales trends, identified top-performing countries, compared regional performance, and evaluated revenue contribution across different sales channels.
